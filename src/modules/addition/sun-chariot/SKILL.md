# Konark Sun Chariot Wheels — Open Specification

## 1. Overview & Learning Objectives
* **Module ID:** `addition.sun-chariot`
* **FLN Code:** `FLN-NUM-FACT-FAM`
* **NCERT Alignment:** Grade 1 & 2 (*Wheel in Konark Sun Chariot & Number Pairs*)
* **Core Concept:** Number decomposition and additive fact families arranged radially around a central hub.

## 2. Pedagogical Framework
1. **Radial Geometry Representation:** Spoke nodes with $a + \square$ pointing inwards to hub $H$.
2. **Commutative Symmetry:** Highlights that $2 + 7 = 9$ and $7 + 2 = 9$ occupy complementary spokes.
3. **Interactive Feedback:** Each correct number glows green and snaps into the spoke ring.

## 3. State Machine & Transitions
```
[Select Wheel Hub] ➔ [Highlight Spoke] ➔ [Select Addend] ➔ [Fill Spoke] ➔ [Complete All Spokes] ➔ [Celebration Modal]
```

## 4. Level Progression
* **Level 1 (Hub 7):** $1+6, 6+1, 2+5, 5+2, 3+4, 4+3$.
* **Level 2 (Hub 8):** $7+1, 1+7, 2+6, 6+2, 3+5, 5+3, 4+4$.
* **Level 3 (Konark Hub 9):** Complete 8-spoke chariot wheel.
